# Catalog selection and limits

The nine images are cat, train, star, rabbit, duck, fish, elephant, bear, and spider. No rain, sun, carrot, mouse, web or woodland image is on the board: these could create competing answers in familiar songs. Cat illustrations in the surrounding interface are decoration, not a hint about the current song.

The train songs use the familiar little-engine song rather than Junalaulu (which has several animal passengers). Hämä-hämähäkki maps to its main character, the spider, rather than incidental weather. Rabbit, duck and fish remain distinct illustrations. Titles were checked against Spotify's own public metadata; no track ID is generated or guessed.

27 refers to **recordings**, not 27 different compositions. Alternate performers of familiar songs make early-childhood recognition easier while adding variation. The Fisher–Yates bags use each recording in a category before resetting.

Verification on 2026-10-04: public page HTTP status, track title, artist metadata and source link. `audioVerified` and `finlandPlaybackVerified` are explicitly false. No full audio listening was available. Thematic mapping is an editorial inference from familiar song subjects and titles, not a certified lyric-by-lyric review. A Finnish adult listening review remains advisable, particularly for less familiar recordings such as Karhulapset. If a recording is unavailable or confusing, Skip song is always available in the listening view.

The application contains short original English explanations, not copied lyrics. Spotify URLs are opened externally, never used to download audio or extract hidden playback.
